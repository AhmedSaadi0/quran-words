# خطة التحقق من الجذور التي تبدأ بـ «ى» والجذور الـ62 بلا معانٍ — وإكمال تلخيصها بالذكاء الاصطناعي

> الهدف: تصحيح وتوثيق **كل الجذور التي تبدأ بـ «ى» (68 جذراً مثل `ىمن`، `ىخر`، `ىله`)** — هل هي فعلاً جذر الكلمات في الآيات أم تحريف همزة — **إضافةً إلى الـ62 بلا معانٍ**، ثم جلب معانيها من المعاجم وتحديث قاعدة البيانات، وأخيراً توليد الملخص الشامل لها بالذكاء الاصطناعي بنفس أسلوب بقية الجذور (1,580).

---

## 📊 الوضع الحالي

| العدد | الوصف |
|-------|-------|
| 68 | جذر تبدأ بـ «ى» في `roots` (`SELECT root FROM roots WHERE root LIKE 'ى%'`) — منها 43 بلا معانٍ و25 لها معانٍ (مثل `ىمن` 879 مرة، `ىخر` 250) |
| 62 | جذر بلا أي معنى في `root_meanings` (`data/roots_without_meanings.json`) — 43 منها تبدأ بـ «ى» + 19 أخرى (`هزى`، `دمو`، `زلزل`…) |
| 87 | نطاق التحقق الفعلي = 68 + 19 = 87 جذراً فريداً (الاتحاد) — يُفحص هل كل منها جذر صحيح للكلمات في الآيات أم كلمة أخرى |
| 1,580 | جذر مُلخص فعلياً (`data/root_ai_summary.json` → `quran_words.db:root_ai_summary`) |
| 1,642 | إجمالي الجذور في `roots` |

**أمثلة كاشفة من الفحص الأولي (`word_morphology` → `words` → `ayat`):**

| الجذر المخزن | مثال الآية (word) | اللمّة | الملاحظة |
|---------------|-------------------|--------|-----------|
| `ىله` (id 2) | `ٱللَّهِ` (1:1) `لِلَّهِ` (1:2) | `ٱللَّه` | أصلها `أ-ل-ه` / `إله` — همزة مُنقلبة `ى` |
| `ىخر` (29) | `ٱلْـَٔاخِرِ` (2:8) `وَبِٱلْـَٔاخِرَةِ` (2:4) | `ىْخِر` | أصلها `ء-خ-ر` (آخر) — همزة على كرسي |
| `ىذن` (83) | `ءَاذَانِهِم` / `بِإِذْنِ` | `آُذُن` / `إِذْن` | اختلاط جذر الأذن بالإذن |
| `ىتي` (101) | `فَأْتُوا۟` / `وَأُتُوا۟` | `آَتَY` | همزة + تاء — تطبيع `ء-ت-ي` → `ىتي` |
| `دمو` (141) | `ٱلدِّمَآءَ` (2:30) | `دَم` | واو زائدة — الأصل `د-م` |
| `ىله` تكرر 2,851 مرة في القرآن كمورفولوجيا (أعلى تكرار بين الـ62) |
| `ىمن` (id 22) | `يُؤْمِنُونَ` (2:3) `ءَامَنَّا` (2:8) | `ءَىمَنَ` | يبدأ بـ `ى` لكن له 7 معاجم — هل هو `ء-م-ن` (أمن) أم `ى-م-ن`؟ |
| `ىنس` (237) | `أُنَاسٍ` / `ٱلْإِنسَـٰنُ` | `إِنسَٰن` / `ءَىنَسَ` | خلط `ن-و-س` و `أ-ن-س` |

**النمط العام:** معظمها همزات مُطبَّعة كـ `ى` أو واو/ياء زائدة، أو جذور ثنائية مُمددة (`دمو`←`دم`)، أو أسماء أعلام (`الله`).
**نطاق التوسعة الجديد:** كل الـ68 التي تبدأ بـ `ى` (حتى التي لها معانٍ مثل `ىمن`) ستُستخرج آياتها عبر الربط ويُتحقق هل الجذر المخزن هو فعلاً جذر الكلمات في الآيات أم أن الكلمة تعود لجذر آخر (مثل `ىمن` هل أصلها `أمن`؟).

---

## 🔍 التشخيص — لماذا بلا معانٍ؟

1. **تطبيع الهمزة:** `ء/أ/إ/آ` → `ى` في `roots.root` (مثل `ىخر` بدل `ءخر/أخر`، `ىتي` بدل `ءتي`).
2. **جذور ثنائية/ناقصة:** `دمو`، `بوى` (`ب-و-ء`) — المعاجم تفهرسها تحت `دم`، `بوأ`.
3. **أعلام وضمائر:** `ىله` (الله) — بعض المعاجم لا تفرد لها مادة مستقلة بل تحت `أله/ولِه`.
4. **تفكك الجذر المركب:** `ىذن` يجمع `أذن` (العضو) و`إذن` (الإباحة) في سجل واحد.

النتيجة: البحث الحرفي `WHERE root = 'ىخر'` لا يجد `أخر` في `arabic_roots.json` ولا في `hawramani`.

## 🗺️ مراحل التنفيذ المقترحة

### المرحلة 0 — تصدير الأدلة لكل جذر (يوم 1)

**سكريبت:** `scripts/verify_roots_export.py`

- **أولاً: كل الجذور التي تبدأ بـ «ى» (68)** — استعلام `SELECT id, root FROM roots WHERE root LIKE 'ى%' ORDER BY id`، ثم لكل جذر اجلب **كل الآيات** المرتبطة.
- **ثانياً: بقية الـ62 بلا معانٍ التي لا تبدأ بـ «ى» (19)** — `هزى`، `دمو`، `زلزل`… — نفس الجلب.
- الاتحاد = 87 جذراً فريداً. لكل منها اجلب **كل الآيات** عبر:
  ```sql
  roots r → word_morphology wm (root_id) → word_ayah wa → words w → ayat a
  LEFT JOIN lemmas l
  ```
- اكتب حزمة `/tmp/verify_roots/{root}.json` بها:
  ```json
  {
    "root_stored": "ىخر",
    "root_id": 29,
    "quran_occurrences": 250,
    "distinct_words": ["ٱلْـَٔاخِرِ","وَبِٱلْـَٔاخِرَةِ"],
    "distinct_lemmas": ["ىْخِر"],
    "ayat": [{"surah":2,"ayah":8,"text":"...","word":"ٱلْـَٔاخِرِ","lemma":"ىْخِر"}],
    "arabic_roots_json_match": null,
    "hawramani_candidates": []
  }
  ```
- الخرج يُحفظ في `data/verify_roots/` للمراجعة اليدوية.

### المرحلة 1 — إعادة التحقق من صحة الجذر (يوم 1–2)

**سكريبت:** `scripts/verify_roots_check.py` (يعتمد على مخرجات المرحلة 0)

1. **مقارنة مع `quranic_corpus_morphology.json` و `arabic_roots.json`:** هل الجذر المخزن يطابق `root` في QAC؟ هل مفتاح آخر في `arabic_roots.json` يطابق اللمّة؟
2. **توحيد الهمزة:** قواعد تطبيع: `ى` أولاً → `ء/أ` حسب السياق، `و` زائدة آخراً تُحذف (`دمو`→`دم`).
3. **تصنيف كل جذر (يشمل فحص الـ68 التي تبدأ بـ ى مثل `ىمن`):**
   - `صحيح` — يبقى كما هو (مثل `حصحص` مضعف رباعي صحيح لكن بلا مادة، أو `ىمن` إذا ثبت أن `ى-م-ن` هو التمثيل المعتمد في QAC رغم أن الأصل المعجمي `أ-م-ن`).
   - `مُصحح` — `ىخر`→`ءخر`، `ىتي`→`ءتي`، `دمو`→`دم`، `ىله`→`أله`، و`ىمن`→`أمن` إذا ثبت أن كلمات `يُؤْمِنُونَ`/`ءَامَنَّا` جذرها المعجمي `أمن` لا `ىمن`.
   - `مُركب/مُفكك` — `ىذن` → `أذن` + `إذن` (يُفصل إلى سجلين).
   - `علم` — `ىله`/`الله` — لا مادة معجمية مستقلة، يُعالج كحالة خاصة (ملخص من السياق القرآني).

- الخرج: `data/roots_verification.csv`:
  ```
  root_id,root_stored,root_corrected,status,confidence,example_ayah,note
  29,ىخر,ءخر,مُصحح,0.95,"2:8 ٱلْـَٔاخِرِ","همزة على كرسي الياء"
  2,ىله,أله,مُصحح/علم,0.90,"1:1 ٱللَّهِ","اسم الجلالة — مادة أله/وله"
  ```

### المرحلة 2 — البحث عن المعنى في المعاجم وتحديث القاعدة (يوم 2–3)

**سكريبت:** `scripts/fetch_missing_meanings.py`

- لكل جذر `مُصحح`/`صحيح`: ابحث أولاً في `arabic_roots.json` بالمفتاح المصحح، ثم في `hawramani` (8 معاجم) عبر `source_url` المنمط:
  `http://arabiclexicon.hawramani.com/{root}/?book={id}`
- إذا وُجدت مادة: أضف صفوفاً إلى `root_meanings`:
  ```sql
  INSERT INTO root_meanings (root_id, definition, book_name, source_url) VALUES (...)
  ```
  مع الحفاظ على `root_id` الأصلي (لا يُغير `roots.root` إلا إذا كان التصحيح إجماعياً وموثقاً — وإلا يُضاف `root_corrected` كحقل مساعد).
- إذا لم توجد مادة (مثل `حصحص` النادر): اترك بلا `root_meanings` وسجّل `note: لا مادة معجمية — سيُلخص من السياق القرآني فقط`.

- **تحديث `roots` عند الحاجة:** فقط للجذور `مُصحح` بثقة عالية وموافقة يدوية:
  ```sql
  UPDATE roots SET root = 'ءخر' WHERE id = 29;
  ```
  ويُحدَّث `data/roots_without_meanings.json` تباعاً.

### المرحلة 3 — توليد الملخص الشامل بالذكاء الاصطناعي (يوم 3–4)

**نفس خط الأنابيب المُنجز لـ 1,580 جذراً، مع فروق طفيفة:**

1. **إعادة تصدير الحزم:** `python scripts/export_root_bundles.py --roots "ءخر,أله,دم,..."` → `/tmp/opencode/root_bundles/{root_corrected}.txt` (يقرأ من `root_meanings` بعد التحديث).
2. **طابور جديد:** `python scripts/build_summary_queue.py` — سيكتشف تلقائياً أن الـ62 أصبح لها `root_meanings` و `summary_ar == null` في `data/root_ai_summary.json` (1,580 مُنجز + 62 مُعلق جديد = 1,642).
3. **التوليد:** وكلاء `muse-spark-1.2-contributor-free` (كل وكيل 3–6 جذور، 1–3 ثوانٍ فاصل، `model` يكتبه الوكيل نفسه ديناميكياً كما في `scripts/merge_summaries.py:22` و `scripts/build_root_ai_summary.py:36`).
   - للجذور بلا مادة معجمية (`حصحص`): الملخص يُبنى من السياق القرآني فقط (الآيات المُصدَّرة في المرحلة 0) مع وسم `model` نفسه.
4. **الدمج والتحميل:**
   ```bash
   python scripts/merge_summaries.py
   /usr/bin/python3.13 scripts/build_root_ai_summary.py
   ```

- **حالة خاصة `ىله/الله`:** إن بقيت بلا مادة معجمية، الملخص يُولَّد من السياق العقدي (الربوبية/الألوهية) مع تشكيل وافٍ، ويُوسم `model` الحالي.

### المرحلة 4 — التحقق النهائي والتوثيق

- `python scripts/build_root_ai_summary.py --stats` → المتوقع `1580 + N` حيث `N` عدد الجذور التي وُجد لها معنى من بين الـ87 (62 - حالات العلم البحت + تصحيحات الـ68).
- `python -m backend.manage check` + اختبار `RootSerializer` لحقل `ai_summary_ar` على جذور كانت `null` سابقاً (مثل `ءخر`).
- تحديث `ROOT_AI_SUMMARY_PLAN.md` و `README.md` بإضافة قسم "الجذور الـ62 — التحقق والتصحيح".
- حفظ تقرير `data/verify_roots/report.md` يوثق كل تصحيح مع مثال آية.
